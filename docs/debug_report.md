# Debug Report – Cognitive Adaptive Deception System

Generated: 2026-03-17

## Summary
Audited backend, frontend, infra, and demo services. Primary faults were dependency mismatches, missing configs, and missing telemetry streaming. All identified blockers were fixed. Remaining items are tracked as architecture gaps where implementation exists as lightweight stubs but not full production integrations.

## Issues and Fixes

### 1) ESLint + Next.js mismatch
- **File**: `frontend/package.json`
- **Issue**: `eslint` v9 + `eslint-config-next` v16 broke `next lint`.
- **Root cause**: Version mismatch with Next 14.2.5.
- **Fix applied**: Pin `eslint` to `^8.57.1` and `eslint-config-next` to `14.2.5`.

### 2) Typecheck failures on clean checkout
- **File**: `frontend/tsconfig.json`, `frontend/package.json`
- **Issue**: `.next/types` missing during `tsc --noEmit`.
- **Root cause**: Next mutates `tsconfig` and expects `.next/types` generated by build.
- **Fix applied**: Use `next build` as `typecheck` script.

### 3) Pyre2 missing `pydantic_settings`
- **File**: `.pyre_configuration`, `.vscode/settings.json`, `backend/.vscode/settings.json`
- **Issue**: Pyre couldn’t find site-packages.
- **Root cause**: Wrong interpreter/search path in IDE.
- **Fix applied**: Point Pyre + VS Code to `backend/.venv`.

### 4) Missing backend dependencies
- **File**: `backend/.venv`
- **Issue**: `pytest`, `numpy`, etc. missing in venv.
- **Root cause**: `requirements.txt` not installed.
- **Fix applied**: Install backend requirements.

### 5) Missing telemetry streaming
- **File**: `backend/src/cognitive_deception/streaming/pipeline.py`, `backend/src/cognitive_deception/api/routes.py`
- **Issue**: No WebSocket streaming for dashboard.
- **Root cause**: Pipeline only wrote to Kafka/Elastic.
- **Fix applied**: Added in-memory pub/sub + `/ws/telemetry` WebSocket.

### 6) Start session rejected for honeypot channels
- **File**: `backend/src/cognitive_deception/models/schemas.py`
- **Issue**: `channel` regex rejected `cowrie/dionaea/tcp`.
- **Root cause**: Strict regex allowed only `ssh/http/api`.
- **Fix applied**: Expanded allowed channel pattern.

### 7) Missing geolocation in telemetry
- **File**: `backend/src/cognitive_deception/services/geolocation.py`, `backend/src/cognitive_deception/services/orchestrator.py`
- **Issue**: Events lacked geo context.
- **Root cause**: No geo enrichment.
- **Fix applied**: Added deterministic offline geo mapping and event enrichment.

### 8) No pgvector in DB stack
- **File**: `infrastructure/docker/docker-compose.yml`, `backend/requirements.txt`
- **Issue**: Postgres lacked vector extension.
- **Root cause**: Standard Postgres image.
- **Fix applied**: Use `pgvector/pgvector:pg16` with init SQL, added `pgvector` dependency.

### 9) Honeypot services missing
- **File**: `infrastructure/docker/docker-compose.yml`, `infrastructure/docker/honeypot.Dockerfile`, `honeypot/decoy_server.py`
- **Issue**: Cowrie/Dionaea/Web honeypot absent.
- **Root cause**: No service definition.
- **Fix applied**: Added lightweight emulated honeypot services wired to backend APIs.
