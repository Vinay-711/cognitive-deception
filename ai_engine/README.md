# AI Engine

This module contains lightweight, dependency-minimal AI components intended to be
used as an integration layer in demos. It is designed to be swapped with full
PyTorch + LangChain models in production.

Modules:
- `behavior_classifier.py`
- `intent_predictor.py`
- `deception_policy_engine.py`
- `attack_graph_builder.py`
